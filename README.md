# Fred Mockup Generator

## Français

<!-- Présentation générale de l'outil -->
Fred Mockup Generator permet de créer rapidement des données factices pour les maquettes de vos applications.

### Actions

1. **Définir le schéma** : ajoutez des champs, donnez-leur un nom et choisissez le type de données à générer. Vous pouvez également supprimer un champ et définir le nombre de lignes.
2. **Générer l’aperçu** : lancez la génération pour afficher les données produites dans le tableau d’aperçu avant l’export.
3. **Exporter en CSV** : choisissez le séparateur souhaité, puis exportez les données générées dans un fichier CSV.

## English

<!-- General presentation of the tool -->
Fred Mockup Generator helps you quickly create mock data for your application mockups.

### Actions

1. **Define the schema**: add fields, give them names, and choose the type of data to generate. You can also remove a field and set the number of rows.
2. **Generate the preview**: generate the data and display it in the preview table before exporting.
3. **Export to CSV**: choose the preferred separator, then export the generated data to a CSV file.
